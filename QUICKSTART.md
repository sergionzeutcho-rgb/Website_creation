## What You Can Do in the Admin Panel

### 1. Add Products
- Go to "Products" → "Add New Product"
- Upload product images
- Set pricing
- Write descriptions
- Control display order

### 2. Customize Hero Section
- Go to "Hero Section"
- Change main title and subtitle
- Upload hero image
- Update location and hours

### 3. Manage Bookings
- Go to "Bookings"
- View all customer requests
- Confirm or cancel bookings
- Filter by status
- Email is now required for all bookings

### 4. Control Availability (NEW!)
- Go to "Availability"
- **Time Slots**: Add/remove/enable/disable available time slots
- **Block Dates**: Block entire days (holidays, vacations)
- **Block Specific Slots**: Block individual time slots on specific dates
- **Settings**: Configure max bookings per slot, advance booking days, etc.
- Enable/disable booking system entirely

### 5. Edit "Our Maison" Section
- Go to "Maison Section"
- Update about text
- Change image

### 6. Site Settings
- Go to "Settings"
- Update contact information
- Add phone number
- Set Instagram handle
