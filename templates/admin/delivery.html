💡 How Delivery Zones Work

  • Enter postcodes as comma-separated values (e.g., "SW1, SW2, W1, W2")
  • Use postcode prefixes to match entire areas (e.g., "SW" matches all SW postcodes)
  • System checks zones in order - first match wins
  • Set different fees for different areas (e.g., £3 for local, £5 for outer zones)
  • Use inactive zones to temporarily disable delivery to certain areas
